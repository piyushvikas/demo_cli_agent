# Examples

Copy-paste ready workflow examples for ops-factory.

## 🔨 AI-Powered Development (Forge)

| Example | Use Case |
|---------|----------|
| [forge-review.yml](forge-review.yml) | AI code review + deterministic secret scanning on every PR |

## Setup

1. Copy the example file to your repo's `.github/workflows/` directory
2. Configure required secrets in your repository settings
3. Adjust inputs as needed for your project
4. Open a pull request — Forge review and secret scanning run automatically
